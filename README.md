# 身边的物理 · EVERYDAY PHYSICS

日常器物与物理原理图鉴。26 件你每天都会碰到的东西，每一件都先把现象逐条写清，再拆到能算的数字，并顺手纠正流传最广的错解。每件东西最后附一段克制篇幅的英文简述。

覆盖 13 个物理分支：量子力学、原子分子与光谱、原子核与粒子物理、电动力学与电磁学、光学、凝聚态与固体物理、热力学与统计物理、流体力学、相对论与天体物理、经典力学与理论力学、物理实验、量子光学与激光光谱、气象学与大气科学。

## 数据一览

日常器物 26 件。物理分支 13 个。现象详述 242 节，约 5.5 万字，平均每件 2116 字。现存实例 153 项，其中 92 项带来源链接。进阶实例 205 项，约 3.36 万字，其中 114 项带来源链接。可核验关键数字 128 组。误传澄清 61 条。外部来源去重后 65 条。英文简述 26 段共 2020 词，平均每段 78 词。

## 详情页的层次

1. 一句话结论：这件东西到底靠哪条物理规律在工作。
2. 现象详述：只写观察到的事实与条件依赖，机制留到下一节。要求覆盖六类内容，见下。
3. 背后的原理：解释上一节那些现象为什么发生，分小节展开。
4. 现存实例：真实存在的对象、设施或已记录案例，尽量给出可核验来源。
5. 进阶实例：同一条物理规律在更高量级上运行的真实工程对象（在役工业装置、大科学装置、尖端产品、国家级基准），每条标注所属装置或行业类别。
6. 关键数字：频率、波长、温度、效率、厚度、浓度等可核验数值。
7. 常见误传说：流传最广的错误解释，逐条给出正确版本。
8. 设计上的取舍：工程师在哪些约束之间做了折中。
9. 书库坐标：对应到本地物理书库的主题目录。
10. 外部来源：原始论文、政府与标准机构文件、大学课程讲义。
11. 英文简述：与中文正文同一组事实的英文简版，只做对应，不引入中文部分没有的数字。

实例层的收录标准：只收真实存在的对象，不写泛称类别，不把「国家标准规定」「行业通常做法」这类条文或惯例当实例；每条必须能给出可核对的来源链接或可检索的专有名称；不收发明时间线式的小知识与人物典故，除非它本身就是正在运行的装置。

现象层的六类要求：随条件变化（功率、尺寸、材质、温度、湿度、朝向、时间）、时间演化（最初几秒与几分钟后、数小时后）、边界与失效情形、反直觉细节、可感知量级、不同档次产品的差别与常见误判。禁止空话，同一句式不得跨器物复制。

## 形式约束

全站遵守以下硬约束，`verify.js` 会逐条断言，改版时不得放宽：

1. 极致紧凑：正文 14px、行高 1.5，全部纵向间距不超过 18px；宽屏（不小于 960px）长文自动分两栏，把详情页滚动长度压到接近一半。
2. 无图片：不使用位图、矢量图、图标字体，不设背景图，不引用媒体标签。现象层只用文字描述，不靠插图代替描述。
3. 无表格：不使用 HTML 表格系列标签；关键数字、书库映射、误传总表、来源总表、现存实例与进阶实例一律用列表与网格行呈现。
4. 无 emoji：不使用任何 emoji 码位，也不使用箭头、圈号等符号作装饰。数据中的乘号仅作数学乘号使用。
5. 无搜索：没有搜索框、没有搜索逻辑、没有筛选控件；按分支浏览由 themes.html 承担。
6. 无星号加粗标记：强调一律由样式表的字号、字重与颜色承担。

## 证据分级

A 级：有实验结论、原始论文（含期刊与 DOI）或权威机构数据支撑，数字可直接引用。

B 级：来源为成熟技术资料、行业标准范围或权威科普。原理无争议，具体数值属行业常见区间。

未收录：来源单一、数字相互矛盾、或只能找到二手转述的条目，本版一律不收。

## 重新生成

内容不是手写 HTML，而是从结构化数据生成的。条目与原理改 `data_a.py` / `data_b.py`，现象与实例改 `expand_*.py`，进阶实例改 `inst_*.py`，英文简述改 `en_*.py`，然后：

```bash
python build.py
```

索引页、分支页、方法页、全部详情页与 `data/items.json` 会自动重建；新增一节现象、一项实例、一项进阶实例或一段英文简述，会自动进入对应页面与本页的统计。

## 验证

```bash
NODE_PATH=<node-workspace>/node_modules node verify.js
```

用 jsdom 真实加载页面并断言：形式约束（无表格、无图片、无搜索、无 emoji、无星号标记、间距上限、双栏），索引页卡片与统计，26 个详情页的现象小节数、实例数、进阶实例数、英文简述正文、数字行数、误传条数与来源条数是否与数据逐条一致，进阶实例与英文简述的体量、覆盖率与禁用符号，内部链接完整性，翻页边界，方法页聚合。当前 48 项断言全过。

布局另用无头 Chromium 在 320 / 390 / 999 / 1280 / 1440 五种宽度下实测：横向溢出、文字截断、区块间距、分栏是否生效，均须为零问题。

```bash
python tools/layout_probe.py
python tools/layout_shot.py
```

前者把布局指标注入页面后用 `--dump-dom` 取回并判定，后者只截图指定区块供人工核对。两者都只在系统临时目录里操作副本，不改动站点文件。

## 说明

- 数值取的是典型值或量级，不是某一型号的出厂参数。
- 「一句话结论」是提炼后的表述，需要精确表述时以来源原文为准。
- 现象层以可观察事实为准，机制存争议时在文中标明，不强行给出单一定论。
- 纯静态站点，无外部脚本、无统计代码、无追踪、无个人数据。
